## 🎯 Key Features
- **Business Dashboard:** Create orders, assign riders, track live statuses, search, filter, and cancel orders.
- **Rider Dashboard:** View assigned deliveries, accept jobs, update status (Picked Up, In Transit, Delivered).
- **Customer Tracking:** Real-time visual timeline tracking with rider contact details and live status updates.
- **Role-Based Access Control (RBAC):** Dynamic role-switching for seamless demo and role testing.
- **Activity Log & Notifications:** Centralized real-time simulation feed for status updates across all panels.
- **Production Ready:** Fully responsive design, input validation, robust error handling, and optimized performance.

## 🛠️ Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS / CSS Modules
- **State & Context:** React Context API (`AuthContext`)
- **Icons:** Lucide React
